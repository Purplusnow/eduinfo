| 용어 | 뜻 |
| --- | --- |
| 가·나·다군 | 정시모집의 모집 시기 구분. 군별로 한 번씩, 최대 3곳에 지원할 수 있습니다. |
| 경쟁률 | 지원자 수 ÷ 모집 인원. 수능 최저학력기준이 있으면 실질 경쟁률은 더 낮습니다. |
| 기회균형전형 | 저소득층, 농어촌, 특성화고졸, 장애인 등 대상자에게 기회를 주는 전형. 정원 외 모집이 많습니다. |
| 내신 | 학교생활기록부의 교과 성적. 2025년 고1부터 5등급 상대평가로 바뀝니다. |
| 모집요강 | 대학이 모집 전에 발표하는 전형 안내서. 전형 방법, 일정, 제출 서류가 담긴 가장 정확한 자료입니다. |
| 미등록 충원 | 합격자가 등록하지 않아 생긴 빈자리를 예비 순위대로 채우는 것(추가 합격). |
| 백분위 | 나보다 점수가 낮은 수험생의 비율. |
| 변환표준점수 | 탐구 과목 간 난이도 차이를 보정하려고 대학이 백분위를 바탕으로 다시 계산한 점수. |
| 선행학습 영향평가 | 대학별 고사(논술·면접)가 고교 교육과정을 벗어났는지 대학이 스스로 점검해 공개하는 보고서. 기출 분석 자료로 유용합니다. |
| 세특 | 과목별 세부능력 및 특기사항. 학생부종합전형의 핵심 평가 자료입니다. |
| 수능 최저학력기준 | 수시 합격을 위해 넘겨야 하는 수능 등급 조건. |
| 시행계획 | 대학이 입학 연도 기준 1년 10개월 전에 공표하는 전형 계획. 예: 2028학년도 시행계획은 2026년 4월 공표. |
| 입결 | 입시 결과. 합격자의 성적 분포(50%컷, 70%컷 등)를 말합니다. |
| 정원 내·외 | 입학 정원에 포함되는지 여부. 정원 외 전형은 별도 인원을 뽑습니다. |
| 지역인재전형 | 비수도권 대학이 해당 지역 고교 출신을 선발하는 전형. 의·치·한·약학 계열은 일정 비율 이상 선발이 의무입니다. |
| 추가모집 | 정시까지 뽑지 못한 인원을 2월 중에 다시 모집하는 것. 수시 합격자는 지원할 수 없고, 4년제 정시 등록자는 정해진 기한까지 등록을 포기해야 지원할 수 있습니다. |
| 표준점수 | 원점수를 평균·표준편차로 보정한 점수. 시험이 어려울수록 최고점이 올라갑니다. |
| 학생부교과전형 | 내신 성적 중심 수시 전형. |
| 학생부종합전형 | 학생부 전체를 정성 평가하는 수시 전형. |
| 환산점수 | 대학이 자체 공식으로 수능·학생부 성적을 합산한 점수. |
